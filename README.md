# Manga Store 📚

Proyecto fullstack de tienda de mangas.

## 🚀 Tecnologías
- React + Vite
- Spring Boot
- MySQL

## ✨ Funcionalidades
- Listado de mangas
- Búsqueda por título
- Carrito de compras
- Creación de órdenes

## ▶️ Cómo ejecutar

### Backend
cd manga-store,
./mvnw spring-boot:run

### Frontend
cd manga-store-frontend,
npm install,
npm run dev
